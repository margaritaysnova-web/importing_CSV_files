## Описание проекта

Модуль представляет собой веб-приложение на базе ASP.NET Core MVC, предназначенное для наполнения каталога электронного магазина товарами. Данные считываются из CSV-файла, проходят валидацию, и корректные записи сохраняются в оперативной памяти (без использования базы данных). 

**Реализованный функционал:**
- Чтение CSV-файлов с поддержкой кавычек и пустых полей.
- Строгая валидация данных по требованиям варианта «Электроника» (обязательный бренд, гарантия от 0 до 60 месяцев).
- Защита от дубликатов артикулов (SKU) как внутри файла, так и в памяти.
- Отображение подробного отчета об импорте (всего строк, успешно, ошибки) с указанием номеров строк.
- Просмотр списка загруженных товаров с подсчетом общей стоимости.
- Хранение данных в памяти с использованием паттерна Singleton (данные не теряются при переходах между страницами).

## Технологический стек

- **Язык:** C#
- **Платформа:** .NET 9 (совместимо с .NET 8)
- **Фреймворк:** ASP.NET Core MVC
- **Тестирование:** xUnit
- **Фронтенд:** Razor Views + Bootstrap (встроенный)

## Структура проекта

- `Controllers/` — `ProductsController` (обработка HTTP-запросов)
- `Models/` — модели данных (`Product`, `ImportResult`, `ImportError`, View-модели)
- `Services/` — бизнес-логика (`InMemoryProductRepository`, `ProductImportService`, `CsvLineParser`)
- `Views/` — пользовательский интерфейс (представления)
- `wwwroot/csv/` — папка с тестовыми CSV-файлами (`sample_products.csv`)
- `tests/` — проект с unit-тестами (xUnit)

## Инструкция по запуску

### Требования
- Установленный **.NET SDK 8.0 или 9.0**.
- **Visual Studio 2022** (с рабочей нагрузкой «ASP.NET and web development») или **VS Code** с расширением C#.

### Запуск через Visual Studio
1. Откройте файл решения `.sln` или `.slnx`.
2. Убедитесь, что в качестве запускаемого проекта выбран `Pr02Ber`.
3. Нажмите **F5** (или кнопку «Пуск» / Start).
4. В браузере откроется главная страница. Используйте кнопки навигации или перейдите по адресам:
   - Страница импорта: `https://localhost:xxxx/Products/Import`
   - Список товаров: `https://localhost:xxxx/Products/Index`
